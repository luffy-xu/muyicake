# Loop: i18n Chinese + English

## Objective

Add bilingual public UI support with Chinese as the default language and English as optional.

## Routes

- `/`
- `/qixi`
- `/custom`
- `/en`
- `/en/qixi`
- `/en/custom`

## Tasks

- Add typed Chinese and English dictionaries.
- Add language switcher that preserves equivalent route.
- Localize public header, hero, product cards, form labels, validation display, success modal, FAQ, sticky CTA, WhatsApp templates, and SEO metadata.
- Store `locale: "zh" | "en"` on reservations.
- Show locale in admin.

## Acceptance Criteria

- Chinese renders by default.
- English renders under `/en`.
- English submissions store `locale = "en"`.
- Chinese submissions store `locale = "zh"`.
- Admin can see reservation locale.
