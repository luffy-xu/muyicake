# Product Brief

## Brand

MuYi Cakes SG / 沐伊蛋糕新加坡

## MVP

A mobile-first ToC cake reservation site in Singapore.

## Traffic

Users arrive from:
- Instagram
- Xiaohongshu
- TikTok
- WhatsApp groups
- WeChat / friends referral
- Google search later

## Core Flows

### Qixi Flow

Social post → `/qixi` → select 4" or 6" qixi cake → fill WhatsApp, name, date, area → submit → success modal → WhatsApp follow-up.

### Daily Custom Flow

Social/search/referral → `/custom` → select birthday/custom type → fill WhatsApp, name, date, area, optional details → submit → success modal → WhatsApp follow-up.

## Pricing

Qixi:
- 4" S$77
- 6" S$117

Daily:
- 4" birthday From S$77
- 6" birthday From S$117
- Kids/theme/celebration From S$157
- Corporate From S$177

## Non-goals

- No payment
- No cart
- No user password login
- No real AI image generation
- No complex CMS
