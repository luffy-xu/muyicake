# Design Audit

Check visual and mobile experience.

## Must Pass

- Mobile-first design at 390px width.
- Warm cream / blush pink / rose pink visual direction.
- Product cards are visually clear.
- CTA buttons are obvious.
- Sticky bottom CTA exists.
- Placeholder cake images are used cleanly.
- Page feels like a premium cake gift brand, not a generic form.

## Fail Conditions

- Looks like admin dashboard.
- Looks like cheap coupon page.
- Desktop-first layout.
- CTA hidden below too much content.
- Form feels too long before user understands value.
